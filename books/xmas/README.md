# Book: xmas — Christmas Storybook

This is the first book on the shelf. It owns everything specific to the
Christmas story; the page-turn engine, tilt rig, and music player are shared
(top-level `assets/`). See `skills/book-authoring.md`.

## Contents

```

  index.html                entry page (so books/xmas/ is a short link)
  pages.js                  the 14-page roster (tree → Santa → elf → reindeer → fireplace)
  cover.svg                 shelf-card preview art
  favicon.svg               reindeer-head icon (moved from assets/favicon.svg)
```

## Status

Runs from `books/xmas/index.html` (so `books/xmas/` is a short link), loading the
shared engine (`../../assets/`) plus the per-book content here. `og.png` is the
`og:image`; `og.svg` is regenerated by `node tools/build-previews.js xmas`.

## Story (14 pages)

Christmas tree → Santa → Elf → a text-only interlude → the nine reindeer
(Dasher … Rudolph) → a "Merry Christmas!" fireplace finale.

## Reindeer config

`buildReindeer(cfg)` accepts:

| key           | values                                                                 |
| ------------- | ---------------------------------------------------------------------- |
| `fur`         | hex colour of the coat                                                 |
| `furDark`     | hex colour for ears / back legs                                        |
| `belly`       | hex colour of the belly + muzzle patch                                 |
| `antlerStyle` | `wide` \| `tall` \| `bushy`                                            |
| `antlerColor` | hex colour of the antlers                                              |
| `nose`        | `red` (Rudolph) \| `brown`                                             |
| `accessory`   | `none` \| `scarf-<colour>` \| `collar` \| `vest-green` \| `vest-red` \| `santa-hat` |

(antler **style** and antler **colour** are separate fields — don't merge them.)

## Backdrop

`backdrop.js` (`mountWinter`): moon, hills, decorated pines, a string of
Christmas lights, and animated canvas snowfall (frozen to a still frame under
`prefers-reduced-motion`).
